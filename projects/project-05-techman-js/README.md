##  Описание проекта

Разработана низкоуровневая TypeScript-библиотека для полноценного взаимодействия с промышленным коллаборативным роботом Techman TM5-700 по протоколу TCP/IP через интерфейс Listen Node. Библиотека реализует самостоятельную сборку бинарных пакетов, расчет контрольных сумм (XOR), валидацию длины данных и парсинг ответов робота — без использования сторонних SDK.

Библиотека опубликована в открытом доступе и может использоваться как основа для построения собственных систем управления роботом.

---

## ⚙️ Архитектура

Кодовая база разделена на три логических слоя:

1. **`protocol/builders`** — формирование текстовых пакетов протокола Techman, автоматический расчет байтовой длины и контрольной суммы (checksum) в формате HEX.
2. **`protocol/parsers`** — валидация входящих пакетов от робота (проверка целостности по CRC) и маршрутизация (router) по типам заголовков.
3. **`network`** — управление TCP-сокетами, сборка фрагментированных сетевых чанков в единые пакеты (`PacketFramer`) и отслеживание асинхронных ответов (`ResponseTracker`).

## 📦 Поддерживаемые заголовки (пакеты)

| Заголовок | Назначение |
|-----------|------------|
| **TMSCT** (Script) | Отправка системных команд, конфигурации базы/TCP и команд перемещения (PTP, Line, Circle) |
| **TMSTA** (Status) | Запрос состояния Listen Node и выполнения очередей тегов |
| **TMSVR** (Value) | Чтение и запись внутренних переменных робота (в режиме String) |
| **CPERR** (Packet Error) | Обработка и парсинг протокольных ошибок формата |

## 📂 Состав материалов проекта

### Исходный код
В папке `code/` представлены ключевые файлы библиотеки:
1. **`tm-script-connection.ts`** — главный класс, объединяющий соединение и клиент скриптов.
2. **`packet-builder.ts`** — формирование исходящих пакетов с расчетом checksum.
3. **`packet-parser.ts`** — парсинг и маршрутизация входящих пакетов.

### Диаграмма
Файл `diagrams/class-diagram.pdf` содержит UML-диаграмму классов и интерфейсов библиотеки, отражающую архитектуру клиентского слоя и протокольных компонентов.
