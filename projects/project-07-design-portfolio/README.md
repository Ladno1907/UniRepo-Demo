## 🎯 Описание проекта

Разработан дизайнерский отчет-портфолио, систематизирующий результаты внеучебного проекта по промышленным роботам-манипуляторам. Документ выполнен в формате профессионального портфолио с использованием инфографики, визуализации 3D-моделей и структурированного представления технических данных.

Отчет описывает комплекс разработок, включающий:
- Универсальные захватные устройства для промышленных роботов
- Модульные конструкторы для демонстрации возможностей манипуляторов
- Механические и электромеханические манипуляторы
- Программное обеспечение для управления роботами

---

## 🎨 Дизайнерские особенности

- **Профессиональная верстка**: документ оформлен в стиле корпоративного портфолио с единой визуальной системой
- **Инфографика**: технические характеристики и данные проектов представлены в виде наглядных схем и диаграмм
- **3D-визуализация**: модели роботов и компонентов интегрированы в дизайн отчета
- **Типографика**: использованы современные шрифты и иерархия заголовков для улучшения читаемости
- **Цветовая система**: единая палитра, соответствующая фирменному стилю университета
