##  Описание проекта

Разработано fullstack-приложение, которое принимает произвольный текст из веб-интерфейса, рассчитывает его геометрию по сетке физического рабочего поля манипулятора и транслирует в траектории движения робота TM5-700. Приложение демонстрирует практическое применение библиотеки `techman-js` и показывает, как стороннее устройство (ноутбук) может полноценно управлять промышленным роботом.

---

## ⚙️ Ключевая функциональность

1. **Векторные шрифты на JSON** — реализован собственный парсер кастомных шрифтов, где каждый символ описан массивом элементарных геометрических команд (`up`, `down`, `line`, `blend`, `circle`).
2. **Динамический маппинг текста** — алгоритм автоматически разбивает строку на слова, переносит строки по границам физического рабочего поля манипулятора и масштабирует координаты глифов с сохранением пропорций.
3. **Интерактивный HTML5 Canvas предпросмотр** — фронтенд имитирует поведение робота, отрисовывая сетку ячеек и будущую траекторию движения маркера (включая сглаживание углов `blend` и дуги `circle`).
4. **Конвейерная обработка буфера** — так как буфер команд робота ограничен 15 тегами (`QueueTag`), сервер реализует асинхронный опрос состояния и подливает новые буквы в память робота по мере выполнения старых.

##  Состав материалов проекта

### Исходный код
В папке `code/` представлены ключевые файлы приложения:
1. **`server.ts`** — Express-сервер, все API-эндпоинты, интеграция с файловой системой.
2. **`runRobotProcess.ts`** — асинхронная логика управления роботом, конвейерная отправка команд.
3. **`textMapper.ts`** — алгоритм расчета координат букв на поле с учетом масштаба.

### Диаграмма
Файл `diagrams/sequence-diagram.pdf` содержит диаграмму последовательности, отражающую полный цикл взаимодействия: User → WebUI → Server → File System → TMFlow (робот).

### Дизайн интерфейса
Файл `design/interface-screenshot.webp` содержит скриншот пользовательского интерфейса приложения. Дизайн разработан отдельно и не является частью программной реализации.
