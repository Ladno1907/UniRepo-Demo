## 🎯 Описание проекта

Разработано модульное захватное устройство для промышленного робота TM5-700. Система состоит из **универсального базового модуля** и **четырёх сменных насадок** под различные производственные задачи. 

Все насадки присоединяются к базе через **байонетное соединение**, которое обеспечивает быструю смену инструмента и передачу крутящего момента от сервопривода, интегрированного в универсальный захват.

### Ключевые особенности
- Модульная архитектура с быстросменным байонетным соединением
- Единый сервопривод в базовом модуле для всех типов насадок
- Адаптивность под различные типы манипуляторов (промышленные, электромеханические, механические)

## 📂 Состав материалов проекта

### 3D-визуализация
В разделе 3D-модели представлена интерактивная сборка, демонстрирующая принцип байонетного соединения базового универсального захвата и насадки с конической передачей. Модель можно вращать и рассматривать со всех сторон прямо в браузере.

### Конструкторская документация (Чертежи)
Проект сопровождается комплектом чертежей, выполненных в соответствии с требованиями ЕСКД:
1. **`drawing-marker.pdf`** — Захват для маркеров (кулачковая передача)
2. **`drawing-conical.pdf`** — Насадка с конической передачей
3. **`drawing-rack.pdf`** — Реечный параллельный захват
4. **`drawing-three-finger.pdf`** — Трёхпальцевый захват

### Паспорт изделия
Файл `product-passport.pdf` содержит сводные технические характеристики, габаритные размеры, типы механических передач и нагрузочные способности для всех четырёх насадок.
