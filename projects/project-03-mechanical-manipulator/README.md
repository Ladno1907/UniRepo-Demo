## 🎯 Описание проекта

Разработан механический четырехосевой манипулятор с полностью ручным управлением. Конструкция базируется на системе зубчатых и ременных передач, включая планетарный редуктор в основе привода. 

Проект включает полноценное проектирование всех узлов, расчет зубчатых передач и подготовку комплекта конструкторской документации. Манипулятор спроектирован таким образом, чтобы быть совместимым с универсальным модулем захвата, разработанным для промышленного робота TM5.

## 📂 Состав материалов проекта

### 3D-модели
1. **`manipulator-with-cover.glb`** — манипулятор в полной сборке с защитными крышками.
2. **`manipulator-without-cover.glb`** — манипулятор со снятыми крышками для демонстрации внутреннего устройства и системы зубчатых передач.

### Конструкторская документация
1. **`drawing-overall.pdf`** — сборочный чертеж с габаритными размерами.
2. **`drawing-views.pdf`** — чертеж с тремя ортогональными проекциями (видами) изделия.
