## 🎯 Описание проекта

Разработан физический модульный конструктор, предназначенный для сборки робототехническими манипуляторами. Проект решает задачу точного позиционирования и надежного соединения деталей в процессе автоматизированной сборки, а также демонстрирует адаптивность конструкции под разные типы приводов.

---

## ⚙️ Конструкторские особенности

В конструкции реализован ряд инженерных решений для обеспечения точности и надежности сборки:

1. **Точное позиционирование:** Для увеличения точности совмещения деталей при сборке в модули встроены магниты диаметром 5 мм.
2. **Система «Якорь»:** Наличие специального посадочного места позволяет возводить строения вне зависимости от точного местонахождения базовой площадки.
3. **Крепление к поверхности:** Для обеспечения надежности крепления всей конструкции к рабочей поверхности используются разъемное соединение и мощные базовые магниты.
4. **Модульность:** Система позволяет комбинировать элементы для создания новых объектов и конфигураций, расширяя библиотеку задач для манипулятора.

### 3D-модели
В папке `models/` представлены два варианта сборки:
1. **`house-assembled.glb`** — финальная собранная модель (домик).
2. **`house-exploded.glb`** — разобранная модель, демонстрирующая модульную структуру, внутренние элементы и посадочные места.
