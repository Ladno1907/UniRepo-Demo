## 🎯 Описание проекта

Разработан электромеханический трехосевой манипулятор, приводимый в действие шаговыми двигателями. Проект включает полноценное конструирование всех механических узлов, разработку электронной платы управления на дискретных компонентах и создание проводного пульта оператора.

Конструкция использует конические зубчатые и ременные передачи для обеспечения точного позиционирования осей. Манипулятор полностью совместим с универсальным модулем захвата для TM5.

## 📂 Состав материалов проекта

### Механическая часть
1. **`models/manipulator-assembly.glb`** — полная 3D-модель сборки манипулятора.
2. **`docs/drawing-views.pdf`** — чертеж с тремя видами изделия.

### Электронная часть
Проект включает разработку печатных плат управления на базе дискретных компонентов (без использования микроконтроллеров), что демонстрирует глубокое понимание схемотехники.

**Ключевые компоненты:**
* **Двигатели:** Шаговые двигатели FL42STH47-0806B (NEMA 17, момент 3.17 кг·см).
* **Питание:** Блок питания 24В, 100Вт; преобразователь XI4016.
* **Логика:** Микросхемы серий K176, CD40xx, HEF4093, K155 (триггеры, логические элементы).
* **Силовая часть:** MOSFET-транзисторы AO4606, AO3400A.
* **Управление:** ИК-приемник TSOP31238, переменные резисторы.

*(Если у вас есть 3D-модели плат в формате GLB, они размещаются в папке `electronics/models/`)*
